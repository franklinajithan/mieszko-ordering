# Promo labels
Apply scripts/promo-labels.sql to the existing PostgreSQL database before use. Set PROMO_IMAGE_DIR to a persistent writable directory outside the checkout. Copy existing barcode.webp files into that directory, or upload through /promo. Protect /promo and /api/promo with the same office authentication proxy as the rest of the application. Browser print supports Save as PDF. The initial label uses text branding pending the original logo asset. Existing catalogue records are read-only; manually supplied label metadata is saved in separate promo tables. Excel import accepts the existing headerless A–H layout, max 5000 rows per batch. WebP files only. Run npm run build and test on staging before deployment.
